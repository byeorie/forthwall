# 웹툰 제4의 벽 파괴 내용분석 코딩 도구

코드북 v0.3 기반의 **컷 단위** 코딩 도구입니다. GitHub만으로 돌아갑니다(별도 서버 없음).

- **코더**: 배포된 웹 주소로 접속 → 아이디(coder1~) + 비밀번호 4자리 → 작품 순서대로, 컷마다 없음 / 파괴 시작 컷 / 이어지는 컷을 표시
- **master**: 이 PC에서 `index.html`을 더블클릭 → 작품·컷 분할 세팅 → `배포하기.bat`

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 프로그램 본체 (코더 화면 + master 세팅 모드) |
| `codebook.js` | 코딩 항목. 이 파일만 고치면 코딩 화면이 바뀜 |
| `config.json` | 저장소 정보 + 계정별로 암호화된 열쇠 (세팅 모드에서 자동 생성) |
| `data/works.json` | 작품 목록·컷 분할 (세팅 모드에서 자동 생성) |
| `data/img/…/*.bin` | 암호화된 웹툰 이미지 (비밀번호 없이는 볼 수 없음) |
| `private/accounts.json` | **비밀번호와 이미지 열쇠. GitHub에 올라가지 않음** |
| `배포하기.bat` | 더블클릭하면 GitHub에 올림 |

코더 결과는 GitHub 저장소의 `results` 브랜치에 `results/coder1.json` 형태로 저장됩니다.

## 처음 한 번: 배포 준비

1. **저장소 만들기**: github.com → New repository → 이름 입력 → **Public** → Create
2. **웹사이트 켜기**: 저장소 Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save
   → 주소: `https://사용자명.github.io/저장소이름/`
3. **토큰 만들기**: GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Expiration: 연구 기간에 맞게(최대 1년)
   - Repository access: **Only select repositories** → 위 저장소 하나만
   - Permissions → Repository permissions → **Contents: Read and write**
4. `index.html` 더블클릭(크롬/엣지) → 프로젝트 폴더 선택 → **⚙ 계정·저장소 설정**에 사용자명·저장소 이름·토큰 입력 → 설정 저장
5. 작품 세팅(아래) 후 `배포하기.bat` 더블클릭

## 작품 세팅 (master, 이 PC)

1. `index.html` 더블클릭 → 「↺ 지난 폴더 다시 열기」 (비밀번호 없이 바로 시작)
2. **＋ 새 작품** → 작품ID·작품명·플랫폼·장르·회차 입력
3. **🖼 이미지 여러 장 선택** → 한 회차의 쪼개진 이미지를 한꺼번에 선택 (파일 이름 순서대로 여백 없이 이어 붙음)
4. 이어 붙은 이미지 위에서 **드래그**해 컷을 하나씩 지정 (번호는 읽는 순서대로 자동)
   박스 이동·크기 조절 · ⤓ 다음 컷과 합치기 · Delete 삭제
5. **💾 저장** → 다 끝나면 `배포하기.bat` (1~2분 뒤 코더 화면에 반영)

왼쪽 목록의 ▲▼로 코딩 순서를 바꿀 수 있습니다. 컷 번호는 코딩 전에 고정해야 합니다. 코딩이 시작된 뒤에는 컷을 **지우거나 다시 나누지 마세요**.

## 결과 받기

배포된 주소에 **master**로 로그인 → 📊 진행 현황 → **전체 CSV 내보내기**
(컷 1개당 1행, 코드북 6장 시트 구조. 파괴 없는 컷·이어지는 컷은 코딩 열 모두 0(이어지는 컷은 지속 여부=1). 층위는 L3·L2·L1 각 0/1 + 층위 수. 엑셀·구글시트에서 한글 정상)

## 알아둘 점

- 비밀번호 4자리는 “잘못 들어가는 것 방지”용입니다. 작정한 사람이 공개된 `config.json`을 컴퓨터로 대입 공격하면 풀 수 있는 수준이므로, 이미지 보호는 일반 방문자 차단 정도로 생각하세요.
- 토큰이 만료되면 코더 화면에 “토큰 만료” 경고가 뜹니다. 새 토큰을 만들어 설정 저장 → 배포하면 됩니다.
- 코더 작업은 브라우저에 즉시, GitHub에는 최대 1분 간격으로 저장됩니다.
